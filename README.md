# Olist Ecommerce Analytics Dashboard

## Project Overview

This project is an end-to-end Ecommerce Analytics Dashboard built using **Power BI, PostgreSQL, and DAX** on the Brazilian Olist Ecommerce dataset.

The dashboard transforms raw ecommerce data into actionable business insights by analyzing:

- Sales Performance
- Customer Behavior
- Seller Performance
- Delivery & Logistics
- Payment Trends
- Product Reviews
- Revenue Growth
- Category Insights

The project focuses on business intelligence, operational analytics, KPI tracking, and interactive reporting.

# Key KPIs

| KPI | Description |
|---|---|
| Revenue | Total sales generated |
| Orders | Total completed orders |
| AOV | Average Order Value |
| On-Time % | Percentage of on-time deliveries |
| Avg Rating | Average customer rating |
| YoY % | Year-over-Year revenue growth |
| Revenue per Seller | Seller efficiency metric |

---

# Key Business Insights

- Late deliveries significantly reduce customer ratings.
- Credit cards dominate ecommerce payment methods.
- A small number of categories contribute the majority of revenue.
- Delivery performance varies across customer states.
- High-performing sellers generate a significant share of platform revenue.
- Customer satisfaction is strongly linked to delivery performance.
